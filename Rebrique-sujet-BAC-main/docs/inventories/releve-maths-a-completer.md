manque deux données par exercice : le **thème** et le **barème**. Elles ne
peuvent pas être copiées d'une autre année, et les chiffres de ces fichiers
sont corrompus : il faut les lire sur le sujet.

thème et le barème de chaque تمرين dans le tableau ci-dessous, et renvoyez-le-
moi. Je l'encode immédiatement. Le texte « candidat » extrait du fichier est
là pour vous aider : il est incomplet (lettres manquantes), ne le recopiez pas.
