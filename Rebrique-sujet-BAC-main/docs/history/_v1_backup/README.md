# بوصلة كنز المنهجية 4D - المنصة التفاعلية لبكالوريا الجزائر
## مادة علوم الطبيعة والحياة

تم دمج المعايير النفسية والبيداغوجية المهدئة:
1. **ساس التنفس والتأطير النفسي (Box Breathing):** لخفض القلق وإعادة التوازن الذهني قبل الامتحان.
2. **الميكرو-فلاش كاردز (Micro-Flashcards):** ومضات بصرية موجزة تعوض النصوص الطويلة المربكة.
3. **زر فك القفل الذهني (Panic/Rescue Helper):** تلميحات ذكية فورية عند الشعور بالبلوكاج.
4. **شريط التقدم البصري اللمسي:** إظهار التقدم خطوة بخطوة لتعزيز الثقة بالنفس.
5. **معاينة PDF وعزل الموضوع المعتمد:** تصفح كامل للموضوعين قبل الاختيار، وعزل تام للموضوع المعتمد.
