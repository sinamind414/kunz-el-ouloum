أطلس التقنيات التجريبية والمخبرية
1. التصوير الإشعاعي الذاتي (Autoradiographie) :

تتبع مسار ومصير الجزيئات داخل الخلايا بعد وسمها بنظير مشع (كاليوراسيل المشع أو الثيميدين المشع).

2. تقنية الرحلان الشاردي (الهجرة الكهربائية) :

فصل الجزيئات المشحونة (الأحماض الأمينية والبروتينات) في مجال كهربائي ودرجة pH محددة حسب شحنتها الصافية.

3. تقنية الانتشار المناعي (أوكتارلوني Ouchterlony) :

إثبات نوعية الأجسام المضادة وتشكيل المعقدات المناعية في هلام الجيلوز عند ظهور أقواس الترسيب.

4. تقنية Patch-Clamp :

عزل قطعة غشائية تحتوي قناة شاردية واحدة أو أكثر ودراسة التيارات الكهربائية الداخلة والخارجة.
