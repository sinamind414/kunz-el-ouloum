# Mentions légales

_Version 1.0 — 9 septembre 2026._

## Éditeur et responsable scientifique

**MIFTAH — مفتاح الكنز**, projet open source porté par les contributeurs du dépôt `Allintelligence2024/Rebrique-sujet-BAC`.

Responsable éditorial et scientifique : **l’équipe MIFTAH**. Le projet doit désigner une personne ou une structure joignable avant toute mise en production publique. Tant que cette désignation n’est pas renseignée, la publication est une préversion technique et ne constitue pas une validation scientifique indépendante.

Contact de signalement : ouvrir une issue GitHub dans le dépôt du projet. Ne pas publier de données personnelles ni de copie nominative. Pour une demande privée, utiliser le canal de contact de l’organisation GitHub propriétaire du dépôt.

## Hébergement

GitHub Pages est le choix envisagé pour l’hébergement, mais l’instance et son exploitant légal ne sont pas vérifiés dans ce dépôt. Le nom légal de l’éditeur, son adresse et l’identité de l’hébergeur doivent être complétés avant production ; aucune identité ne doit être inventée.
