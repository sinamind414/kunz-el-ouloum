## Pièges de couche texte constatés (pour les encodeurs Phase 3)

- La couche texte **n'est pas** une source : elle rend « التمرين الأول » correct
  mais déforme les libellés d'axes et de réactifs (les lettres س، ص، ع، ل، م des
  réactions couplees et les valeurs de V disparaissent ou se collent).
- Sur les schémas, **les légendes ne sont pas dans la couche** : éléments 1-4 de
  la mitochondrie, éléments 3-5 du modèle 3D de l'ADN, colonnes du tableau
  Anagène (0, 10, 380 ; a, b) — tout est lu sur l'image.
- Les rapports se lisent en clair sur l'image mais exigent un zoom (×2 et plus)
  pour les حَرَكات dans le texte (الـ ATP, الأنزيم (E), الغشاء الداخلي).
